# Panorama Universal — sitio web

Sitio institucional de Panorama Universal, hecho con Next.js y Tailwind CSS y publicado en Vercel.

- Los textos están en `app/content.ts`.
- El diseño de la página está en `app/page.tsx`.
- El logo está en `public/logo.png`.

## Desarrollo local

```bash
npm install
npm run dev
```
